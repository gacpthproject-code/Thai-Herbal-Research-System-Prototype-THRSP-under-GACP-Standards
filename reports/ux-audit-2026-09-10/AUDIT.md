# UX Audit — หน้าชำระเงิน และ หน้าบันทึกการปลูก

2026-09-10 · วัดจากซอร์สจริงบน main `52388976` · ทุกตัวเลขมาจากการนับไฟล์ ไม่ใช่ความเห็น

## ข้อค้นพบระดับระบบ — แก้ที่เดียว ได้ผลทั้งแอป

**ปุ่มทั้งแอปไม่มีขนาดไหนถึง 48px เลย** (`components/ui/primitives/button.tsx:36-44`)

| size | ความสูง | เทียบมาตรฐาน 48px |
|---|---|---|
| `compact-xs` | 24px | **ครึ่งเดียว** |
| `compact-sm` / `xs` | 28px | −20px |
| `compact-md` | 32px | −16px |
| `sm` | 36px | −12px |
| `md` ← **ค่าเริ่มต้น** | 40px | −8px |
| `lg` ← ใหญ่สุดที่มี | 44px | −4px |

ผู้ใช้ "กดไม่ค่อยถูก" ไม่ใช่เพราะไม่ตั้งใจ — ระบบไม่เคยให้เป้าที่ใหญ่พอตั้งแต่แรก

## อ่านตัวเลขนี้อย่างไร

**1. Touch target — ตกทั้งสองหน้า**
หน้าชำระเงินไม่มีปุ่มไหนถึง 48px เลยแม้แต่ปุ่มเดียว นี่คือหน้าที่ผู้ใช้ต้องกดถูกที่สุดในระบบ

**2. One Primary Action — ตกทั้งสองหน้า**
บันทึกการปลูกมี 13 ปุ่มที่ตาอ่านว่า "สำคัญ" พร้อมกัน · 73 สิ่งที่กดได้ในเรื่องเดียว คือตรงข้ามกับ "Focus means saying NO"

**3. Intelligent Inputs — ตกทั้งสองหน้า**
`inputMode` **ศูนย์จุดทั้งแอป** ⇒ ช่องกรอกตัวเลข (จำนวนต้น พื้นที่ เงิน) เด้งคีย์บอร์ดตัวอักษรบนมือถือทุกครั้ง
หน้าชำระเงินไม่มี placeholder เลยสักช่อง

**4. Feedback — ตกหนักที่หน้าชำระเงิน**
27 ปุ่ม มี loading state จุดเดียว ⇒ กดแล้วเงียบ ผู้ใช้กดซ้ำ ซึ่งบนหน้าจ่ายเงินคือความเสี่ยงจริง

**5. Error copy — ผ่าน และดีมากที่หน้าชำระเงิน**
ไม่มี error ดิบรั่วสักจุด และข้อความอย่าง
> "บันทึกการยอมรับเงื่อนไขการชำระเงินไม่สำเร็จ ระบบจึงยังไม่สร้างรายการชำระเงินและยังไม่มีการเรียกเก็บเงิน กรุณากดลองใหม่อีกครั้ง"

บอกครบสามอย่าง: เกิดอะไร · เงินคุณปลอดภัย · ทำอะไรต่อ — **นี่คือมาตรฐานที่หน้าอื่นควรตามให้ทัน**

แต่ฝั่งบันทึกการปลูกยังมี `'บันทึกไม่สำเร็จ'` และ `'บันทึกเก็บเกี่ยวไม่สำเร็จ'` — ทางตัน ไม่บอกว่าต้องทำอะไรต่อ

## ลำดับที่ควรแก้ (ผลลัพธ์ต่อแรงที่ลง)

1. **ขยายปุ่มใน design system** — จุดเดียว ได้ผลทุกหน้า
2. **หน้าชำระเงิน: เหลือปุ่มเด่นหน้าละ 1 ปุ่ม** จาก 11 ที่แข่งกัน
3. **ใส่ `inputMode` ทุกช่องตัวเลข** — คนละบรรทัดต่อช่อง ผลทันทีบนมือถือ
4. **loading state ทุกปุ่มที่ยิงเซิร์ฟเวอร์** — เริ่มจากหน้าชำระเงิน
5. **ยกข้อความ error ฝั่งปลูกให้เท่าฝั่งเงิน**
6. **ลดจำนวนสิ่งที่กดได้ในหน้าบันทึกการปลูก** — ต้องออกแบบใหม่ ไม่ใช่แก้ทีละจุด
