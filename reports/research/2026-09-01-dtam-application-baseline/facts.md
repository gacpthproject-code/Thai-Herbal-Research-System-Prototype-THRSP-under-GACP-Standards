## 1. สิ่งที่แบบ กทล.1 ให้ "กรอก" (ส่วนที่ ๑, ๒, ๔)

### ส่วนที่ ๑ — ตัวตนผู้ขอ (เลือกหนึ่งประเภท กรอกเฉพาะหัวข้อของตน)
| ประเภท | ช่องที่ฟอร์มขอ |
|---|---|
| ๑.๑ วิสาหกิจชุมชน | ชื่อประธาน · ชื่อวิสาหกิจ · เลขบัตร ปชช. ประธาน · สัญชาติ · รหัสทะเบียน สวช.01 · เลขรหัสประจำบ้าน · ที่อยู่ตามทะเบียนบ้าน · โทรศัพท์มือถือ · อีเมล (ถ้ามี) |
| ๑.๒ บุคคลธรรมดา | ชื่อ-สกุลเจ้าของแปลง · เลขบัตร ปชช. · ที่อยู่ · โทรศัพท์มือถือ · อีเมล (ถ้ามี) · Line ID |
| ๑.๓ นิติบุคคล | ชื่อนิติบุคคล · ชื่อผู้มีอำนาจลงนาม · เลขทะเบียนนิติบุคคล/เลขผู้เสียภาษี · ที่อยู่ · โทรศัพท์มือถือ · อีเมล (ถ้ามี) · Line ID |

หัวฟอร์มมีช่องประเภทคำขอ: รายใหม่ (ปลูก+เก็บเกี่ยว / แปรรูป) · ต่ออายุ (อ้างเลขใบรับรอง) · ใบแทน (สูญหาย/ถูกทำลาย) — ต่ออายุ/ใบแทน **ไม่ต้องกรอกส่วนที่ ๑-๒**

### ส่วนที่ ๒ — ข้อมูลการขอ (ทั้งหมดที่ฟอร์มขอ ไม่มีมากกว่านี้)
- วัตถุประสงค์: ☐ เพื่อใช้ทางการแพทย์ ☐ เพื่อการส่งออก
- ลักษณะพื้นที่: ☐ กลางแจ้ง (Outdoor) ☐ อาคาร/โรงเรือนระบบปิด (Indoor) ☐ โรงเรือนทั่วไป (Greenhouse) ☐ อื่น ๆ ระบุ
- ๑. ชื่อสถานที่ (พื้นที่ปลูก/แปรรูป) + ที่ตั้ง + โทรศัพท์ + โทรสาร (ถ้ามี)
- ๒. ข้อมูลแปลงปลูก/แปรรูป: ประเภทเอกสารที่ดิน เลขที่/เล่ม/หน้า/ออกโดย · สถานะการถือครอง (เจ้าของ/ได้รับอนุญาตใช้ที่ดินรัฐ/เช่า+ชื่อผู้ให้เช่า) · ขนาดพื้นที่ (ตารางเมตร) · ค่าพิกัดภูมิศาสตร์ · ปริมาณการปลูก (ต้น/รอบ, รอบ/ปี)
- ๓. พันธุ์และส่วนของกัญชาที่ใช้: เมล็ด (ชื่อพันธุ์ นำเข้า/ในประเทศ แหล่งที่มา ปริมาณ) · ส่วนอื่นที่ไม่ใช่เมล็ด (สายพันธุ์ แหล่งที่มา ปริมาณ) · กรณีแปรรูป: ส่วนของพืช/สายพันธุ์/แหล่งที่มา/ปริมาณ · เกิน 2 ส่วนให้แนบรายละเอียดเพิ่ม

### ส่วนที่ ๔ — คำรับรองตนเอง + ยินยอมเปิดเผยข้อมูล (map เข้า consent step)
(๑) พื้นที่ปลูกอยู่ในคำขอ + มีสิทธิในที่ดินโดยชอบ (กรรมสิทธิ์/ที่ดินรัฐที่ได้รับอนุญาต/เช่าโดยผู้ให้เช่ามีสิทธิให้เช่า) · (๒) ไม่ทำผิดวัตถุประสงค์ · (๓) ไม่เปลี่ยนพื้นที่/เมล็ดพันธุ์/ส่วนที่ใช้โดยไม่ยื่นคำขอใหม่ · (๔) ข้อมูล+เอกสารเป็นจริงครบถ้วน · (๕) รับทราบและพร้อมปฏิบัติตามหลักเกณฑ์ของกรม · + ยินยอมให้หน่วยงานรัฐ/เอกชนเปิดเผยข้อมูลแก่กรมเพื่อพิจารณา และให้กรมเผยแพร่ข้อมูลการอนุญาตเพื่อประโยชน์ราชการ

## 2. เอกสารแนบตอนยื่น — กทล.1 ส่วนที่ ๓ (รายการทางการทั้งหมด)

### กลุ่มบังคับตามกรณี (ทุกประเภทผู้ยื่น)
| # | เอกสาร | เงื่อนไข |
|---|---|---|
| A1 | สำเนาหนังสือแสดงกรรมสิทธิ์/สิทธิครอบครองที่ดิน หรือหนังสืออนุญาตใช้ที่ดินรัฐ | ทุกราย |
| A2 | หนังสือยินยอมจากผู้ให้เช่า/ผู้ให้ใช้ที่ดิน | **เฉพาะกรณีเช่า/ขอใช้ที่ดินผู้อื่น** |
| A3 | แผนที่แสดงที่ตั้ง+พิกัด+เส้นทางเข้าถึง+ขนาดแปลง+สิ่งปลูกสร้างใกล้เคียง | ทุกราย |
| A4 | แบบแปลนอาคาร/โรงเรือน + ภาพถ่ายภายนอกและภายใน | **เฉพาะ Indoor/Greenhouse** |
| A4′ | ภาพถ่ายแปลงปลูกและบริเวณโดยรอบ | **เฉพาะ Outdoor** |
| A5 | แผนการผลิต (ปลูก) + แผนการใช้ประโยชน์/แปรรูป | ทุกราย |
| A6 | มาตรการรักษาความปลอดภัย + วิธีนำส่วนของกัญชาที่เหลือไปใช้ประโยชน์ | ทุกราย |
| A7 | รูปถ่ายสถานที่ผลิต (ปลูก) และการเก็บเกี่ยว | ทุกราย |
| A8 | คู่มือมาตรฐานการปฏิบัติงาน (SOP) | ทุกราย |

### กลุ่มคุณสมบัติผู้ยื่น (ตามประเภท)
| ประเภท | เอกสาร |
|---|---|
| วิสาหกิจชุมชน (ไม่เป็นนิติบุคคล) | สำเนาหนังสือจดทะเบียนวิสาหกิจชุมชน (สถานะยังดำเนินกิจการ + วัตถุประสงค์สอดคล้อง + บัญชีรายชื่อสมาชิก) · หนังสือแสดงว่าผู้ยื่นได้รับมอบหมายให้ดำเนินกิจการแทนวิสาหกิจ |
| บุคคลธรรมดา | หนังสือแสดงว่าดำเนินการภายใต้ความร่วมมือและกำกับดูแลของผู้รับอนุญาตผลิตยาแผนปัจจุบัน/แผนโบราณ/ผลิตภัณฑ์สมุนไพร |
| นิติบุคคล | สำเนาหนังสือรับรองการจดทะเบียนนิติบุคคล (ออกให้ไม่เกิน 6 เดือน) หรือหนังสือจดทะเบียนวิสาหกิจ/วิสาหกิจเพื่อสังคม/สหกรณ์การเกษตร + บัญชีรายชื่อกรรมการ/หุ้นส่วน/สมาชิก · หนังสือแสดงว่าผู้ยื่นเป็นผู้แทน/ผู้มีอำนาจทำการแทน |

### กรณีต่ออายุ: ต้นฉบับใบรับรองเก่า · แผนการปลูกและเก็บเกี่ยว/แปรรูป · แผนการใช้ประโยชน์ · รายงานสรุปผลการดำเนินการที่ผ่านมา
### กรณีใบแทน: ใบแจ้งความ (กรณีสูญหาย) · ใบรับรองเดิม (กรณีถูกทำลาย/ลบเลือน)

### ส่วนสำหรับเจ้าหน้าที่ (ท้าย กทล.1) — checklist ตรวจรับคำขอของ จนท.
1.1 เอกสารประกอบคำขอ: ☐ บัตร ปชช.+ทะเบียนบ้านผู้ยื่น/วิสาหกิจ ☐ หลักฐานจดทะเบียนนิติบุคคล (กรณีนิติบุคคล) ☐ หนังสือมอบอำนาจ+สำเนาบัตรผู้มอบ ☐ สำเนาเอกสารสิทธิ์ที่ดิน ☐ **ใบอนุญาต/หนังสือสำคัญ กรณีการปลูก/แปรรูปกัญชาที่ต้องได้รับอนุญาตตามกฎหมายที่เกี่ยวข้อง** (คือ*ตัวใบอนุญาต* ไม่ใช่แบบคำขอ ภท.)
1.2 ขอบข่ายการรับรอง (รับได้/ไม่ได้) · 1.3 คุณสมบัติผู้ยื่น (ครบ/ไม่ครบ) · 1.4 ผลตรวจเอกสารเบื้องต้น: ☐ ครบถ้วน ☐ **ไม่ครบถ้วน ขอเอกสารเพิ่มเติม ระบุ…** + วันที่ผู้ยื่นจะส่งเพิ่ม → รองรับการขอเพิ่ม**เป็นรายการ** ไม่ใช่ตีกลับทั้งชุด

## 3. สิ่งที่ [ข้อกำหนด] บอกว่าเป็นของ "วันตรวจ ณ แปลง" ไม่ใช่ "วันยื่น"
- บันทึกการซื้อ/ใช้ปัจจัยการผลิต · บันทึกกิจกรรมแปลงปลูก · บันทึกการขายผลิตผล (ข้อ 1)
- ใบรับรองวัตถุดิบ · เอกสารสั่งซื้อ/ใบรับวัตถุดิบ · สต็อกวัตถุดิบ/ผลิตภัณฑ์ · บันทึกการแปรรูป/บรรจุ · เอกสารการขาย/ใบส่งของ · บันทึกทำความสะอาด · บันทึกป้องกันกำจัดแมลง/สัตว์ศัตรู · บันทึกการร้องเรียน (ข้อ 2, และขั้นตอนตรวจข้อ 4-5)
- เก็บเอกสารสมัคร/รายงานตรวจ/ผลรับรอง/บันทึกร้องเรียน ≥ 5 ปี (ข้อ 6)
- โดยปกติกรม**ไม่ตรวจแล็บ** ยกเว้นพบความเสี่ยงปนเปื้อน (ผู้ประกอบการจ่ายค่าตรวจ) ⇒ ผลตรวจน้ำ/ดิน/ช่อดอก/ใบรับรองแล็บ **ไม่ใช่เอกสารบังคับตอนยื่น**
- กระบวนการกรม: ยื่นชุดสมัคร (แบบลงทะเบียน + SOP + เอกสารประกอบ) ทางไปรษณีย์/อีเมลได้ · แจ้งผล ~30 วัน · ตรวจ 3 แบบ (ครั้งแรก/ประจำปี/พิเศษ)

## 4. Ruling ของ operator (2026-09-01) — ผูกการออกแบบ
1. **ยื่นตามกรมเป๊ะ** — ชุดบังคับ = กทล.1 ส่วนที่ ๓ เท่านั้น (ตาม §2 ข้างบน) ไม่มีเกณฑ์เพิ่มของแพลตฟอร์ม
2. หัวข้อ/ตัวเลือกใน wizard ที่เกินความต้องการ DTAM = ตัด (ความเร็วไม่ใช่ปัญหา ความเกินคือปัญหา)
3. **ไม่มีฟีเจอร์มอบอำนาจการยื่น** (หมายเหตุ: "หนังสือมอบหมายดำเนินกิจการแทนวิสาหกิจ" เป็น*เอกสารแนบ*คุณสมบัติของวิสาหกิจตาม กทล.1 — คงไว้ ไม่ใช่ฟีเจอร์มอบอำนาจ)
4. หน้ารีวิวเจ้าหน้าที่ = checklist ตามส่วน จนท. ของ กทล.1 + **พรีวิวเอกสารดูได้ในหน้า** + ขอเอกสารเพิ่มเป็นรายช่อง — เน้น UX
5. เปิดบริการ**กัญชาอย่างเดียว** — พืชอื่นภายหลังเป็นชุด field/กติกาใหม่ ไม่ reuse ของกัญชา
6. การแสดง/จัดเก็บไฟล์ยึดมาตรฐาน + PDPA — คง `Content-Disposition: attachment` บน top-level, เปิดดูผ่าน in-page viewer (subresource) เท่านั้น
7. **รื้อ UX/UI หน้าตรวจทาน (preview) ด้วย** — หน้านี้คือด่านสุดท้ายก่อนเกษตรกรเสียเงิน: ต้องอ่านรู้เรื่อง เห็นเอกสารตัวเองในหน้า แก้ได้ตรงจุด · ยุบสองหน้า (ตรวจทานและส่ง + พรีวิว) เหลือหน้าตรวจทานเดียวที่เป็นความจริงฝั่ง server

หมายเหตุความไม่แน่นอนที่เหลือ (UNVERIFIED): ระบบ e-service ของกรม (cannabis-gacp-thaicam.dtam.moph.go.th) อาจมีรายการอัพโหลดของตัวเองที่ละเอียดกว่านี้ — โดเมนเข้าไม่ได้จากเครื่องนี้ขณะทำวิจัย · ใบอนุญาตปลูกกัญชาตามกฎหมายปัจจุบัน (พ.ร.บ./ประกาศ สธ. ฉบับที่ใช้บังคับ ณ วันยื่น) ต้องยืนยันฉบับก่อน seed กติกา "ใบอนุญาตตามกฎหมายที่เกี่ยวข้อง"
