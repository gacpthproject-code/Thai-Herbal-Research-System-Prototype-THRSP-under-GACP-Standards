รายงานฉบับแรกเขียนว่า “เกษตรกรที่ยื่นครั้งแรกถูกบล็อกที่ขั้น 2 ทุกราย” — ไม่ถูก ปุ่มถัดไปถูกปิดเพราะช่องกรอกตัวตนยังว่าง ซึ่งเป็นพฤติกรรมที่ถูกต้อง และเปิดทันทีที่กรอก (วัดแล้ว: DISABLED ตอนมาถึง · enabled หลังพิมพ์)

สิ่งที่เป็นข้อบกพร่องจริงคือ ข้อความแดงที่โกหก — ระบบบอกว่าอ่านรายการเอกสารไม่สำเร็จ ทั้งที่ไม่มีอะไรล้มเหลว แค่ยังไม่มีร่างให้ถาม — และ รายการเอกสารไม่ขึ้นเลยตลอด session นั้น (slot card = 0 แม้รอ 9 วินาทีหลัง POST draft สำเร็จ) ผู้ยื่นครั้งแรกจึงไม่เห็นว่าต้องแนบอะไรบ้าง แก้แล้วใน C-03 ด้านล่าง

ลำดับการแก้ทำอะไรก่อน

เรียงตามความเสียหายต่อผู้ใช้หารด้วยแรงที่ต้องลง ไม่ได้เรียงตามความยาก

  1. ทำโหมดมืดให้จบ — นี่คือรายการเดียวที่คุ้มที่สุด

    ให้ token พื้นผิวทุกตัวมีค่าคู่สำหรับโหมดมืด แล้ว C-01, C-02, C-06 และครึ่งหนึ่งของ C-05 หายพร้อมกัน รวมถึงช่องกรอกเลขบัตรที่ตอนนี้พิมพ์แล้วมองไม่เห็น ซึ่งเป็นจุดที่ผู้ใช้จะเลิกใช้ทันที

    แก้ 4 ข้อ Critical ด้วยการแก้ไฟล์ CSS 2 ไฟล์

  2. ปลดล็อกผู้ยื่นคำขอครั้งแรก (C-03)

    ตอนนี้เกษตรกรใหม่ทุกคนชนผนังที่ขั้นที่ 2 นี่คือทางเข้าหลักของทั้งแพลตฟอร์ม และเป็นข้อที่ทำให้คนเลิกก่อนได้เห็นอะไรเลย

    แก้ hook เดียว · ควรมี regression test ที่เดินด้วยบัญชีที่ไม่มี draft

  3. ซ่อมหน้าสแกน QR สาธารณะ (C-05, C-07, P-01)

    หน้านี้คือหน้าเดียวที่คนนอกเห็น ทั้งคำเตือนความปลอดภัยที่อ่านไม่ออก หัวเรื่องที่ถูกบัง และความช้า 8.3 วินาที ควรจบในรอบเดียวกัน

    แก้สี 2 บรรทัด · แก้ layout 1 บรรทัด · ทำ API ให้เร็วขึ้นหรือ prerender

  4. ตั้งกติกาตัวอักษรไทย แล้วบังคับด้วยเครื่อง (C-08, P-09)

    ห้าม letter-spacing ติดลบกับข้อความไทย และตั้ง line-height ขั้นต่ำ 1.35 กับหัวเรื่อง เพิ่ม ESLint rule เพื่อไม่ให้กลับมาอีก เพราะทีมรู้เรื่องนี้อยู่แล้วแต่กติกาไม่มีคนบังคับ

    แก้ CSS 3 จุด + rule 1 ตัว

  5. เอา axe เข้า CI

    ทุกข้อ Critical เรื่องสีในรายงานนี้ เครื่องจับได้อัตโนมัติภายในไม่กี่วินาที ถ้ามีด่านนี้ตั้งแต่แรก จะไม่มีข้อไหนหลุดขึ้น production เลย

    ป้องกันปัญหาทั้งตระกูลนี้ถาวร

  6. เลือกตราแบรนด์ให้เหลือหนึ่ง (P-12)

    เป็นงานตัดสินใจมากกว่างานเขียนโค้ด แต่ต้องมีคนตัดสิน เพราะตอนนี้ผู้ใช้เดินผ่านสามตราในสิบวินาที

    ตัดสินใจ 1 ครั้ง · แก้ 3 คอมโพเนนต์
