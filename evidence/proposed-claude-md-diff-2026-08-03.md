## หมายเหตุตาม §3 ของ CLAUDE.md เอง
กฎที่ไม่มี probe = `[DRAFT]` ไม่ถือว่ามีผลจริง — ถ้า operator ต้องการให้ R-PR-1 เป็นกฎจริง
ต้องมี probe คู่กัน เช่น GitHub Action ที่อ่าน PR body แล้ว fail เมื่อ:
1. ไม่มีหัวข้อ `## สรุปสำหรับ operator`
2. ไม่ครบ 3 บรรทัดที่ขึ้นต้นด้วย `1.` `2.` `3.`
3. บรรทัดใดมี pattern ศัพท์โค้ด (`\.js:\d+`, `` `[a-zA-Z_]+\(\)` ``, `[A-Z_]{4,}`)

**orchestrator ไม่ได้เขียน probe นี้** เพราะ `scripts/probes/*` และ `.github/` เป็น operator-owned
