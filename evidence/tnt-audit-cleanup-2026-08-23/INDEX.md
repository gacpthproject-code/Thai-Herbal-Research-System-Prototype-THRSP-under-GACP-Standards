# เก็บกวาดข้อมูลทดสอบ + ปลดการบังคับรายต้น — 2026-08-23

## 1. ข้อมูลทดสอบที่ทีมตรวจ T&T สร้างไว้บน Supabase

workflow ตรวจระบบปลูก (w3x0ag061) เดินกดจริงบน preview ซึ่งใช้ฐานเดียวกับ Supabase
จึงเหลือแถวทดสอบค้างอยู่ ลบแล้วโดยสำรองครบทุกแถวก่อน

```
ก่อนลบ  harvest batches 5 | lots 4 | รอบปลูก 6 | รายต้น 16
ลบ      lots 4 | batches 3 | units 16 | cycles 3
หลังลบ  harvest batches 2 | lots 0 | รอบปลูก 3 | รายต้น 0
        การเก็บเกี่ยวที่ไม่มีรอบปลูก: 0
```

เงื่อนไขการลบ: เฉพาะแถวที่ `createdAt >= 2026-08-23T14:00:00Z` ซึ่งเป็นช่วงที่ทีมตรวจเดินงาน
รอบปลูกทั้งสามชื่อ `AUDIT-R-CHECK` / `QR-AUDIT-CYCLE` / `LANEB-WALK` — ระบุตัวได้ชัด
สำรองไว้ที่ `removed-probe-rows.json`

**แก้คำรายงานที่ผมเคยพูดผิด:** ก่อนหน้านี้รายงานว่า "การเก็บเกี่ยว 1 ใน 5 รายการไม่มีรอบปลูก —
สายโซ่ขาดจริงแล้วบนข้อมูลจริง" — รายการนั้นคือ `BATCH-2569-000016` ที่ทีมตรวจสร้างเองเมื่อ 14:32
วันเดียวกัน พร้อมโน้ต "AUDIT PROBE — do not use" ไม่ใช่ข้อมูลที่มีอยู่เดิม
ช่องโหว่ในสคีมาเป็นเรื่องจริง (`HarvestBatch.cycleId` เป็น nullable) และ agent พิสูจน์ว่าใช้สร้างของลอยได้จริง
แต่คำว่า "ขาดแล้วบนข้อมูลจริง" ไม่ถูก หลังเก็บกวาดแล้วนับได้ 0

**อีกจุดที่รายงานผิด:** เคยบอกว่า "สมดุลมวลยังไม่มีตัวคุม" — ผิด ตัวคุมมีอยู่จริงและทำงานได้
ทีมตรวจกดจริงได้ `400 LOT_WEIGHT_QUOTA_EXCEEDED` มีทั้ง lock และ fail-closed
สิ่งที่เป็นปัญหาคือ**เพดาน**ต่างหาก: `HarvestBatch.dryWeight` แก้ขึ้นได้ผ่าน `PUT /api/harvest-batches/:id`
โดยไม่มีบันทึกว่าใครแก้ ⇒ ตัวคุมมี แต่ปลดได้จากประตูหลัง

## 2. คำเตือนความปลอดภัยจากระบบ — ตรวจแล้ว

การแก้ตอน 15:30 เป็นการซ่อมกลับของตัวเอง — ลบทิ้งทั้งหมดแล้วตามข้อ 1

## 3. ปลดการบังคับให้มีรายต้นก่อนเก็บเกี่ยว

`harvest-capacity-operations.js` เดิมปฏิเสธการเก็บเกี่ยวถ้ารอบปลูกไม่มีแถว `PlantUnit`
ซึ่งทำให้ระบบรายต้นกลายเป็นภาคบังคับโดยปริยาย — เกษตรกรที่ทำตามดีไซน์ปัจจุบัน (R8: ความละเอียด
จบที่แปลง) จะไม่มีรายต้นให้สร้าง จึงเก็บเกี่ยวไม่ได้เลย ทางเดียวคือเปิดสวิตช์สร้างรายต้น
ซึ่งเป็นเหตุผลว่าทำไมทุกรอบที่เปิดมาถึงวันนี้ถึงมีรายต้นติดมาด้วย

RED ก่อน:
```
× does not refuse a harvest just because the cycle has no plant units
  Expected: not "Plant units must be generated before harvest"
Tests: 1 failed, 1 passed
```
GREEN หลังถอดประตู:
```
√ does not refuse a harvest just because the cycle has no plant units
√ still refuses when the certificate is missing, so removing the unit gate did not open the cert gate
Tests: 2 passed
```

เทสตัวที่สองมีไว้พิสูจน์ว่าถอดประตูรายต้นแล้วไม่ได้เผลอเปิดประตูใบรับรองตามไปด้วย
