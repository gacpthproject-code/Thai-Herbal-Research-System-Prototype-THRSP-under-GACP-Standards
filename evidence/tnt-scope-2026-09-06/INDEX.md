เท่าไหร่ · เกษตรกรอัปเดต/ดู/สแกนได้แค่ไหน · พนักงานติดตามเห็นข้อมูลฟาร์มได้แค่ไหน"

## 1. สาธารณะ — ไม่ต้องล็อกอิน

`evidence/ui-walk-2026-09-06/` · สัญญา: `integration/both-public-scan-paths-agree`,
`integration/public-scan-scope-contract`, `unit/public-farm-projection`

- เห็น: ชื่อฟาร์ม · ที่อยู่เต็ม (เลขที่ ตำบล อำเภอ จังหวัด รหัสไปรษณีย์) · ไฟล์ COA เปิดอ่านได้ ·
  เลขที่ใบรับรองและสถานะ · วันเก็บเกี่ยว · น้ำหนักจริง
- ไม่เห็น: พิกัด GPS (ถามแยกและตอบว่าไม่เปิด) · ชื่อเจ้าของ · id ภายในทุกชนิด ·
  ชื่อแปลง/ชื่อรอบปลูก · ตัวเลขคาดการณ์ผลผลิต
- **ประตูสแกนมีสองเส้น** และวันนี้ทั้งสองเส้นตอบเรื่องเดียวกันแล้ว (ก่อนหน้านี้ไม่)

  (ประกาศ สธ. สมุนไพรควบคุม ข้อ ๔(๖)(๗)) — ป้ายที่ปักอยู่กลางแปลงตอบใครก็ได้ที่เดินผ่าน

## 2. เกษตรกร — เจ้าของข้อมูล

สัญญา: `integration/farmer-tnt-flow`, `integration/tnt-scope-contract`

- เห็นและแก้ไขเฉพาะฟาร์มของตัวเอง
- ถามถึงฟาร์มของคนอื่น → คำตอบ **ไม่ยืนยันแม้แต่ว่าฟาร์มนั้นมีอยู่** (วัดจริง: `Farm not found`)
- ข้อมูลหลังจุดตัด (ออก QR แล้ว) แช่แข็ง · `notes` ยังแก้ได้ · ค่าแล็บพิมพ์เองไม่ได้ ต้องแนบไฟล์

## 3. พนักงานติดตาม — มติ "เห็นข้อมูลทั้งหมด · ฟาร์มทุกประเทศ"

สัญญา: `integration/tnt-scope-contract`, `unit/farm-access-is-recorded`

วัดจากของจริงวันนี้:

```
GET /api/provider/planting-cycles  (โทเคนผู้ตรวจเอกสาร)
→ เห็น 2 รอบปลูก จาก 2 ฟาร์ม คนละเจ้าของ ไม่มีการมอบหมายใด ๆ ผูกอยู่
```

และการเปิดดูครั้งนั้นเขียนบันทึกทันที (PDPA ม.39):

```
FARM_DATA_VIEWED  {"surface":"provider:planting","method":"GET",
                   "path":"/api/provider/planting-cycles",
                   "farmIds":["82668fb8-…"],"farmCount":1,"query":{"limit":"5"}}
```

บันทึกเก็บ **รหัสฟาร์มและคำค้น** ไม่เก็บชื่อฟาร์มหรือชื่อคน — ปูมการเข้าถึงต้องไม่กลายเป็น
สำเนาที่สองของข้อมูลที่มันเฝ้าอยู่

รายการที่พนักงานเห็นก็ไม่พก PII ของเกษตรกรมาด้วย: กว้างที่ "ฟาร์ม" ไม่ใช่กว้างที่ "คน"
