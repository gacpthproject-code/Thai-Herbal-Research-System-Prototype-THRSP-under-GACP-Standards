## 3. วิธีบันทึกผล

- ติ๊กข้อใดต้องมีผลรันในวันนั้น (บรรทัดที่สคริปต์พิมพ์ หรือภาพหน้าจอ) แนบในรายงาน deploy · ค่าของ env ไม่พิมพ์ รายงานแค่ ใช่/ไม่ใช่
- ข้อที่ไม่ผ่านในสภาพแวดล้อมใด = ไม่เผยแพร่ประโยคหรือฟีเจอร์ที่ข้อนั้นค้ำอยู่ในสภาพแวดล้อมนั้น (ข้อ 1.6)
- เอกสารนี้แก้ได้เมื่อมติเปลี่ยน และต้องอ้างเลขคำสั่งที่เปลี่ยน
