# ทะเบียนฐานทางกฎหมาย — ข้อผูกพันไหน บังคับด้วยอะไร และตรงไหนที่ยังไม่มีเครื่องบังคับ

**2026-09-05** · เอกสารนี้ไม่ได้เขียนเพื่อสรุปว่าเราทำอะไรไปบ้าง แต่เขียนเพื่อตอบคำถามเดียว
ที่ผู้ตรวจของกระทรวงจะถามก่อนคำถามอื่นทั้งหมด: **"ข้อผูกพันข้อนี้ ใครบังคับ และพิสูจน์ยังไง"**

หลักของ repo นี้คือ *กฎที่ไม่มีเครื่องบังคับ = กฎร่าง* (CLAUDE.md) · ทะเบียนนี้จึงแยกสามชั้น
ให้ชัดและไม่ปนกัน:

| ป้าย | ความหมาย |
|---|---|
| **[CODE]** | มีโค้ดปฏิเสธจริง และมีเทสที่จะแดงถ้าเอาการปฏิเสธออก |
| **[POLICY]** | ตกลงกันไว้เป็นลายลักษณ์อักษร แต่ไม่มีเครื่องปฏิเสธ — คนต้องทำตามด้วยวินัย |
| **[GAP]** | รู้ว่าต้องมี ยังไม่มี และรู้ว่าทำไมยังไม่มี |

ทุกแถวที่ติด **[CODE]** ตรวจแล้วว่าไฟล์นั้นมีอยู่จริงและมีเทสจริง (ตรวจ 2026-09-05) —
ไม่ใช่การอ้างจากความจำ

## 6. สิ่งที่ทะเบียนนี้บอก และสิ่งที่มันไม่ได้บอก

**บอก**: ทุกข้อผูกพันที่เรารู้ ณ วันนี้ ถูกจัดชั้นแล้วว่าใครบังคับ · ข้อที่ติด **[CODE]**
มีทั้งการปฏิเสธจริงและเทสที่จะแดงถ้าเอาการปฏิเสธออก

**ไม่ได้บอก**: ว่ารายการนี้ครบทุกข้อกฎหมายที่เกี่ยวข้อง · เอกสารนี้เขียนจากข้อผูกพันที่งาน
จนถึงวันนี้แตะถึง ไม่ได้เขียนจากการสำรวจกฎหมายทั้งหมดที่ใช้กับการปลูกกัญชาในประเทศไทย
การอ้างว่าครบโดยไม่ได้สำรวจ จะเป็นคำกล่าวอ้างชนิดเดียวกับที่ทั้งโปรเจกต์นี้พยายามกำจัด

**สามข้อที่ควรทำต่อ ตามลำดับความเสี่ยง**:
1. **[GAP] ม.30 วรรคสอง** — สวิตช์ปิดบันทึกรายรายการพร้อมเหตุผล · ตอนนี้เป็นเปิดหมด/ปิดหมด
2. **[GAP] ทะเบียนสายพันธุ์** — ทำให้ (๓) บังคับได้ครบ ไม่ใช่แค่ครึ่งพื้นที่ปลูก
3. **[POLICY → CODE] W14** — เอกสารการเงินยังเป็นข้อเสนอ · เส้นทางเงินเป็น Tier C
   ซึ่ง agent เสนอ diff ได้แต่ merge ไม่ได้ (L3) จึงต้องรอ operator
