## TOP 5 GAP เสี่ยงสุด (เรียงตามความแรงต่อ demo + ความเป็น design-gap)

### 🥇 GAP-1 · Multi-tenant isolation ไม่บังคับจริง (RLS inert) — **demo blocker สูงสุด**
RLS เปิดบน ~50 ตาราง **แต่ policy คืน TRUE เสมอ + app ไม่เคย set `app.tenant_id` GUC** → Postgres ไม่กันอะไรเลย · app-layer org-scope flag `TENANT_READ_ORG_SCOPE` **DEFAULT OFF ใน prod compose** · ไม่มี automated cross-tenant test (มีแค่ manual staging script) → **leak ข้าม org เงียบ ๆ ได้จริง** (operator ระบุเองว่าอันตรายสุด). ต้องพิสูจน์ด้วย J12 ทันที.

### 🥈 GAP-2 · จ่ายเงินจบไม่ได้บน FE (Golden Path ขาดตรงกลาง)
web-app **ไม่มี `@stripe/stripe-js` / ไม่มี confirm step / ไม่ render PromptPay QR** และไม่ใช้ `clientSecret` ที่ backend คืน · `STRIPE_CHECKOUT_ENABLED` default false + keys BLOCKED → **GP-3 เดินไม่จบ** ⇒ J1 (เกษตรกรจ่ายเงิน) ตันแน่ (C1 Payment Wave 3-4 คืองานปิด gap นี้).

### 🥉 GAP-3 · ความน่าเชื่อของใบรับรอง (documentHash ไม่มี key) — #619 CONFIRMED
`documentHash` = **unkeyed SHA-256** (certificate-service.js:52) → แก้ DB แล้ว recompute ได้ ⇒ integrity ปลอมได้ · signing key ไม่เสถียร/namespace ไม่ provision (signature-service.js:353-358) → **ใบขึ้น amber ไม่ใช่เขียว** · ห้ามพูดว่า "ปลอมไม่ได้".

### GAP-4 · เกือบทั้งระบบไม่มี real-DB/E2E proof (green ≠ ครบ)
10/13 ระบบเป็น MOCK-ONLY/PARTIAL ที่ test mock Prisma · real-DB proof ครอบแค่ **~2 จาก ~20 workflow edges** · spec full-lifecycle เดียว (`e2e-golden-scenario`) **assert อะไรไม่ได้เลย (รับ 400/404 ทุก hop)** → "engine เดินครบ" ยัง**พิสูจน์ไม่ได้ด้วยอัตโนมัติ** (ตรงกับความรู้สึก operator "ระบบไม่ครบ").

### GAP-5 · Login จริงยังใช้ไม่ได้ (IdP ภายนอกทั้ง 3 ตัวตาย)
Health ID + ThaID = `coming_soon` ไม่มี adapter · Provider ID adapter ครบแต่ callback จบที่ **409 AUTH_LINKING_PENDING** ไม่ mint session · เดินได้แค่ local + mock IdP · **session ไม่ cookie-only** (JWT อยู่ใน response body — ขัด pin E-4). ⇒ demo login จริงด้วยตัวตนกลางยังไม่ได้.

> **Design-gap ที่ต้องรายงานทันที (นอก top 5 แต่เป็นการออกแบบไม่ใช่ bug):**
> Cert **expiry ไม่เคยถูก persist** (ไม่มี active→expired transition — §7) · **renewal supersession unwired** (§7) · **DTAM remittance-batch ไม่ถูก implement** (recordRemittanceToDtam ไม่เคยถูกเรียก — §4) · Track&trace **ไม่มี hop สินค้า/finished-goods** (จบที่ raw-material lot — §6) · SURVEY **respondent identity กำกวม + read leak ข้าม tenant** (§5).
