# ชุดข้อมูลตัวอย่างสังเคราะห์

ไฟล์ในโฟลเดอร์นี้คือชุดเต็มหนึ่งชุดตามที่คลังข้อมูลวิจัยของโครงการจะได้รับ แตกจากไฟล์ ZIP ของประตู `GET /api/datasets/bundle` ไม่มีข้อมูลของคนหรือฟาร์มจริง

- ที่มา: `node apps/backend/scripts/datasets/check-dataset.js --write-sample` สร้างบัญชี หน่วยงาน บริษัท ฟาร์ม และรอบปลูกสังเคราะห์ แล้วเขียนทุกแถวที่ส่งออกผ่านประตูเดียวกับที่หน้าจอใช้ (แบบสำรวจและคำตอบ บันทึกกิจกรรม รุ่นเก็บเกี่ยว การสแกนคิวอาร์โค้ด การถอนความยินยอม การลบฟาร์ม) ค่าทุกค่ากำหนดไว้ใน `apps/backend/scripts/datasets/lib/sample.js` (seed คงที่)
- กุญแจรหัสแฝงของชุดนี้เปิดเผยในไฟล์ `sample.js` โดยตั้งใจ เพื่อให้ใครก็สร้างซ้ำได้ ไม่ใช่กุญแจของระบบจริง ลายนิ้วมือใน `manifest.json` จึงไม่ตรงกับชุดที่ส่งจริง
- ข้อมูลการทำงานของฟาร์มสามโดเมนส่งออกในชุดนี้ภายใต้มติสังเคราะห์ (`privacyNoticeVersion: synthetic-sample-only`) พร้อมหนังสืออนุมัติจริยธรรมสังเคราะห์ (`reference: SAMPLE-ONLY-0001` ไม่ใช่หนังสือจริง) ที่ใส่ให้เฉพาะ backend ของตัวตรวจ ระบบจริงยังไม่มีมติที่มีผล
- สร้างซ้ำได้: ไฟล์ข้อมูลทุกไฟล์และคู่มือได้ไบต์เดิมทุกครั้ง (ฐานชั่วคราวกำหนดรหัสแถวและเวลาสร้างรายการ และนาฬิกาของ backend เริ่มที่วันคงที่) ส่วน `manifest.json` ต่างกันเฉพาะ `exportedAt` และ `codeRevision` ตัวตรวจ K11 เทียบโฟลเดอร์นี้กับชุดที่สร้างใหม่ทุกครั้ง
- สิ่งที่ชุดนี้แสดง:
  - ภาคและจังหวัดที่มีผู้ตอบน้อยกว่า 5 คนเป็นค่าว่าง แล้วปิดช่องที่เล็กถัดไปจนช่องที่ปิดรวมกันได้อย่างน้อย 5 คน: ภาคเหนือ 6 คน เชียงใหม่ทั้งหมด (แสดงภาคและจังหวัด) · ภาคอีสาน 6 คน ขอนแก่น 5 อุดรธานี 1 (อุดรธานีปิดเดี่ยว ๆ จะเหลือกลุ่มค่าว่างคนเดียว จึงปิดขอนแก่นด้วย ภาคยังแสดง) · ภาคกลาง 3 คนกับภาคใต้ 2 คน (ทั้งสองภาคเป็นค่าว่าง รวมกัน 5 คน)
  - คำตอบที่ไม่ยินยอมหรือยินยอมกับข้อความรุ่นเก่าไม่อยู่ในไฟล์ คำตอบที่ถอนอยู่ในรายการถอน
  - บันทึกกิจกรรมและรุ่นของฟาร์มที่ถูกลบไม่อยู่ในชุดใหม่แต่อยู่ในรายการลบ
  - เบอร์โทรทุกรูปแบบที่คนไทยพิมพ์ (มีวงเล็บ คั่นด้วยจุดหรือทับ 66 ไม่มีบวก +66 (0) ตัวเลขไทย สองเบอร์ติดกัน) อีเมล เลขบัตร (รวมตัวเลขไทย) และรหัสที่พิมพ์ในข้อความหรือในตัวเลือกของคำถามถูกปิด
  - เวลาในข้อมูลฟาร์มเหลือแค่วันที่ตามปฏิทินไทย
  - ค่าที่ขึ้นต้นด้วย = + - @ ใน CSV ถูกกันสูตร
