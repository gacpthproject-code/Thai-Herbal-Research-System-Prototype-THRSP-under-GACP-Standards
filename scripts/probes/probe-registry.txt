#     ตัวไหนไม่มี = gate FAIL — ปิดตระกูล "ตัวตรวจมีแต่ไม่ได้เสียบ" แบบทั่วไป ไม่ต้องไล่ทีละตัว

#   ci                        รันโดย probe-gate.js ทุกครั้งที่ local-gate/full-gate ทำงาน (ไม่มี hosted GitHub
#                             Actions อีกต่อไป — operator สั่งไม่จ่ายบิล 2026-08-14, HARNESS_LOG.md 2026-08-14;
#                             self-hosted runner dispatch ยังไม่เคยพิสูจน์ — 05-BACKLOG.md §4 Q-RUNNER)
#   report                    รันพร้อมกอง ci และพิมพ์ PASS/FAIL แต่ไม่ทำให้ gate แดงเลย · ช่อง waived ต้องเป็น -
#                             และต้องมีเหตุผลที่อ้างคำตัดสินของ operator · ใช้กับตัวเลข KPI ที่ operator สั่งให้รายงานเท่านั้น
#                             · ชื่อ probe ต้องอยู่ใน REPORT_ONLY_RULINGS ของ scripts/ci/probe-gate.js ไม่งั้น gate FAIL

#   manual                    ไม่รันใน CI **ถาวร** — ต้องมีเหตุผลยืนพื้นจริง (เช่น ต้องแตะ DB จริง)
#   manual-until:YYYY-MM-DD   ไม่รันใน CI **ชั่วคราว** — พ้นวันนั้น gate **FAIL** เหมือน waiver หมดอายุ
#                             (ถ้าไม่มีค่านี้ "manual ชั่วคราว" จะจอดตลอดกาล = phantom ตัวเดิมย้ายคอลัมน์)
